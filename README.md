# 📋 TaskMaster - Task Management Application

A responsive **Task Management Application** developed using **AngularJS**, **JavaScript**, **Bootstrap 5**, and **Local Storage**. The application helps teams efficiently create, assign, track, and manage tasks through an intuitive dashboard and user-friendly interface.

Application Link:- https://blessingjohntaskmanagement.vercel.app/ 
---

## 📌 Project Overview

TaskMaster is a single-page web application (SPA) built with AngularJS that centralizes task management within an organization. It provides an easy way to create, edit, delete, search, filter, and track tasks while offering dashboard analytics for better productivity.

This project was developed as part of an **AngularJS Internship Project**.

## 📖 Application Workflow

1. Open the Dashboard.
2. View project statistics.
3. Navigate to **Create Task**.
4. Add a new task.
5. Assign the task.
6. Select priority.
7. Choose status.
8. Set the due date.
9. Save the task.
10. View the task in Task List.
11. Search, filter, or sort tasks.
12. Edit tasks whenever required.
13. Delete completed or unnecessary tasks.
14. Dashboard updates automatically.
